# NetScope 资产测绘平台 · 前端交付 × 后端对接文档

> 当前项目整合说明（2026-11-14）：正式版本已改为复用现有 MySQL `ipv4scan` 和同一 FastAPI
> 进程，不创建 SQLite。当前已接通 `/api/health`、`/api/bootstrap`、`/api/search` 以及
> `/assets/*`、`/analysis/*`、`/agent/*`；平台级 `/api/report` 留待下一阶段。最终接口定义以
> `docs/API接口契约.md` 为准，下文 SQLite 内容仅保留为前端最初的数据字段设计来源。

> 版本：v1.0（2026-11-14）
> 交付方：前端组（已完成，本文档 + `index.html` 即全部交付物）
> 接收方：后端组 —— 当前由现有 FastAPI + MySQL 提供适配接口并同源托管前端。

---

## 1. 平台定位（决定接口边界）

- 本平台是**只读查询与可视化平台**：只提供 查询 / 聚合 / 报告 接口；
- **没有**任何扫描下发接口——扫描采集由采集端完成后写入数据库，平台只读库；
- 全部统计数字由**后端代码聚合生成**（SQL 聚合），前端不参与计算；
- 报告的"分析段落"由后端调 LLM 生成，失败自动降级模板（见 §6）。

## 2. 交付物清单

| 文件 | 说明 |
|---|---|
| `index.html` | 前端单文件应用（原生 JS + ECharts 5 CDN），包含平台可视化和智能体分析页面 |
| `对接文档.md` | 前端字段设计说明；实际接口以 `docs/API接口契约.md` 为准 |

前端无构建步骤、无 npm 依赖，就是一个 HTML 文件。**前端只认 JSON 字段名，不认库表结构**——后端换库（SQLite→MySQL/ES）只要字段名不变，前端零改动。

## 3. 部署形态（重要，先读）

前端所有请求均为**相对路径** `/api/...`，登录页即调用 `GET /api/bootstrap`，失败会提示"后端连接失败"。

- **推荐：同源托管（最简）**。后端把 `index.html` 放到自己的静态目录托管在根路径，例如 FastAPI：
  ```python
  app.mount("/", StaticFiles(directory="frontend", html=True), name="frontend")
  ```
  目录结构：`backend/main.py + frontend/index.html`，同源免 CORS。
  访问 `http://127.0.0.1:8000` 即进入前端。
- **备选：前后端分开部署**（前端放 nginx 等）。二选一：
  1. 后端开 CORS（允许 GET/POST，`/api/*` 全放行）；
  2. 前端改一处：`index.html` 中 `const API = {...}`，把 `'/api'` 换成后端绝对地址。

> ⚠️ 直接双击 `index.html`（file:// 协议）时 fetch 相对路径会失败——**必须经 HTTP 访问**。

## 4. 数据库设计（SQLite，字段名 = 接口字段名）

### assets 表（资产明细，12 字段）

| 字段 | 类型 | 说明 / 取值口径 |
|---|---|---|
| `ip` | TEXT | IP 地址；前端按它打开资产详情抽屉 |
| `port` | INTEGER | 端口号 |
| `proto` | TEXT | 仅 `tcp` / `udp` |
| `service` | TEXT | 服务指纹字符串，如 `nginx/1.24.0`、`OpenSSH 8.9p1`、`SNMPv2 public` |
| `risk` | TEXT | 仅 `high` / `mid` / `low`（前端渲染 高/中/低 徽标） |
| `subnet` | TEXT | 内网为 CIDR（如 `10.0.3.0/24`），公网固定字符串 **`公网`** |
| `loc` | TEXT | 内网固定字符串 **`内网`**；公网为省市（如 `广东省广州市`） |
| `ttl` | INTEGER | TTL 值 |
| `banner` | TEXT | 抓取的服务 banner 原文 |
| `last` | TEXT | 最近探测时间 `MM-DD HH:MM`（如 `11-04 06:23`） |
| `first` | TEXT | 首次发现时间，格式同上 |
| `conf` | REAL | 指纹置信度 0.7 ~ 1.0 |

**口径约定（后端聚合逻辑依赖）**：内网判定 = `subnet != '公网'`；省份统计 = `loc != '内网'` 的记录按 loc 前三位（省/市名）归并。

### trend 表（30 天活跃趋势）

| 字段 | 类型 | 说明 |
|---|---|---|
| `day` | TEXT 主键 | `MM-DD` |
| `hosts` | INTEGER | 当日存活主机数 |
| `ports` | INTEGER | 当日开放端口数 |

## 5. 接口契约（共 4 个）

通用约定：响应 `application/json; charset=utf-8`；参数错误返回 **HTTP 400 + `{"detail": "中文错误原因"}`**；无鉴权（同源内网部署）。

### 5.2 `GET /api/bootstrap` — 初始化数据（登录后一次性拉取）

前端登录成功与否就看这个接口，**必须最先实现**。

**响应**：`{ "overview": {...}, "stats": {...}, "assets": [...] }`

**overview**（概览 KPI，9 个字段）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `host` | int | 存活主机数（DISTINCT ip） |
| `port` | int | 开放端口记录总数（assets 行数） |
| `tcp` / `udp` | int | TCP / UDP 记录数 |
| `svcTypes` | int | DISTINCT service 种类数 |
| `riskHigh` | int | risk='high' 记录数 |
| `newToday` | int | 今日新增主机数（口径自定，演示约 host×2.8%） |
| `tcpPct` | float | TCP 占比百分数（保留 1 位，如 70.1） |
| `privPct` | float | 内网资产占比百分数 |

**stats**（图表数据，6 个字段）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `portTop10` | `[["443", 180], ...]` | 端口 Top10，`[端口号字符串, 数量]`，降序 |
| `svcDist` | `[{"name":"Web 服务","value":210}, ...]` | 服务分布饼图，name 取值：`Web 服务 / 数据库 / 远程管理 / DNS/SNMP / 其他`（按 service 关键词归并：nginx·Apache·Tomcat / MySQL·Redis / OpenSSH·Terminal / BIND·SNMP） |
| `trend` | `{"days":["10-06",...],"hosts":[...],"ports":[...]}` | 30 天趋势，三数组等长、按 day 升序 |
| `riskSubnet` | `{"subnets":["10.0.0.0/24",...],"high":[...],"mid":[...],"low":[...]}` | 各内网 /24 子网的高中低风险堆叠计数，四数组等长 |
| `provinces` | `[["广东省", 35], ...]` | 公网资产省份分布（DISTINCT ip 计数），降序 |
| `highList` | `[{"ip","port","proto","service"}, ...]` | 高危资产明细前 6 条 |

**assets**：全量资产行，字段同 §4 assets 表的 12 字段。

### 5.3 `GET /api/search` — 语法检索（服务端解析过滤）

**Query 参数**：`q`（检索串，默认空）、`page`（页码，正整数，默认 1）

**检索语法**：类 FOFA，`key=value`，多条件用 ` && ` 组合。

| 字段 | 匹配方式 | 示例 |
|---|---|---|
| `port` | 精确（端口转字符串比较） | `port=3389` |
| `proto` | 精确（tcp/udp） | `proto=udp` |
| `service` | 模糊 LIKE | `service=nginx` |
| `subnet` | 精确 | `subnet=10.0.3.0/24` |
| `risk` | 精确（high/mid/low） | `risk=high` |
| `loc` | 模糊 LIKE | `loc=广州` |

**错误**（HTTP 400 + detail）：`page < 1`；条件缺 `=`；使用了不支持的字段。detail 示例：`"不支持的字段：host（可用：loc/port/proto/risk/service/subnet）"`。

**响应**：
```json
{
  "total": 37,          // 命中总数（用于前端分页：总页数 = ceil(total/15)）
  "ms": 3.2,            // 后端查询耗时（毫秒，展示用）
  "rows": [ ... ],      // 当前页 15 条（字段同 assets 行）
  "list": [ ... ]       // 全量命中（前端拓扑/导出用）
}
```
空条件 `q=""` 返回全库。

### 5.4 `POST /api/report` — LLM 巡检报告

无请求体、无 query。

**响应**：
```json
{
  "generated_at": "2026-11-14 17:40:00",
  "engine": "llm",            // "llm" 或 "template"（降级）
  "model": "qwen2.5:7b",      // engine=llm 时为模型名，降级时为 null
  "sections": [
    { "t": "h",   "txt": "网络资产巡检报告（2026-11-14）" },
    { "t": "p",   "txt": "【代码生成】统计截至 … 存活主机 762 · 开放端口 800 …" },
    { "t": "h",   "txt": "一、总体态势分析" },
    { "t": "llm", "txt": "……分析正文……", "src": "LLM 生成" },
    …  // h + llm 成对出现共 4 组：总体态势分析 / 风险研判 / 异常关联 / 处置建议
    { "t": "p",   "txt": "—— 统计数字由代码聚合生成；分析段落由 ……" }
  ]
}
```

**section 类型约定**：`t='h'` 标题行；`t='p'` 普通说明段；`t='llm'` 分析正文段（**必带 `src`**：`"LLM 生成"` 或 `"规则模板（降级）"`，前端渲染来源徽标）。前端按 sections 顺序渲染，顺序即文档结构。

## 6. LLM 接入约定（创新点 01，大模型组只出一个接口）

- 大模型侧只需提供 **OpenAI 兼容的 `POST {base_url}/chat/completions`**（DeepSeek / 智谱 / 通义 / 本地 Ollama 均可）；
- 后端通过环境变量接入：`LLM_BASE_URL`（如 `https://api.deepseek.com/v1` 或 `http://127.0.0.1:11434/v1`）、`LLM_API_KEY`（Ollama 留空）、`LLM_MODEL`（默认 `qwen2.5:7b`）、`LLM_TIMEOUT`（秒，默认 60）；
- 分工：**统计数字全部由代码聚合后注入 prompt，LLM 只写 4 段分析**（每段 80–150 字），要求以 `<<<SEC>>>` 分隔输出；解析到非 4 段即视为失败；
- **任何异常（未配置/网络/超时/结构不符）→ 自动降级规则模板**，报告必有产出，`engine` 字段如实标注。答辩时这一点是"工程可靠性"卖点。

## 7. 联调自测清单（后端自检，全过即可约前端联调）

```bash
# 1. 探活
curl http://127.0.0.1:8000/api/health
# 2. bootstrap：检查 overview.host / stats.trend.days 长度=30 / assets 条数
curl http://127.0.0.1:8000/api/bootstrap
# 3. 检索：组合条件
curl "http://127.0.0.1:8000/api/search?q=risk=high%20&&%20proto=udp"
# 4. 语法错误应返回 400 + detail
curl "http://127.0.0.1:8000/api/search?q=host=1"
# 5. 报告：未配 LLM 时 engine 应为 "template"
curl -X POST http://127.0.0.1:8000/api/report
```

**前端侧验收表现**：
1. 登录页 →"登录成功，已从后端加载 N 条资产记录"（N = assets 条数）；
2. 控制台 KPI / 大屏图表有数据；地图 GeoJSON 走阿里 DataV CDN，断网自动降级省份排行，不依赖后端；
3. 检索输入 `port=3389` 出结果、输入 `host=1` 前端 toast 提示语法错误而非白屏；
4. 报告页显示来源徽标（LLM 生成 / 规则模板）。

## 8. 变更协调

- 后端若要改任何响应字段名 / 结构，**必须先同步本文档并通知前端**，前端字段是硬编码匹配；
- 前端不关心后端用什么语言框架（FastAPI 只是参考选型）、什么数据库，只要 HTTP 契约一致；
- 平台只读边界不许突破：**不要新增任何下发/写入类接口**（采集端落库是另一条链路）。
