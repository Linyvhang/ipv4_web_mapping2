# 可视化模块对接说明（可直接转发）

智能体后端已经提供单 IP 扫描数据、分析结果、任务状态、任务结果和自然语言问答接口。
第一版请优先完成单 IP 分析结果页面。

## 推荐页面流程

1. 用户输入 IPv4；
2. 调用 `GET /assets/{ip}/analysis` 查询是否已有报告；
3. 有报告则直接展示；
4. 没有报告时，由用户点击“开始分析”，调用 `POST /analysis/ip/stream`；
5. 根据流式节点事件展示分析进度；
6. 收到 `result` 后展示最终报告。

## 页面建议展示

- 摘要：IP、扫描批次、资产类型、风险等级、置信度；
- 服务：端口、协议、服务类型、产品、版本、Banner；
- 风险：等级、标题、说明、置信度；
- 证据：风险对应的扫描或指纹依据；
- 建议：处置建议和优先级；
- 限制：常用端口扫描、版本缺失等数据限制；
- 进度：LangGraph 当前执行节点。

## 主要接口

```text
GET  /assets/{ip}/scan-data
GET  /assets/{ip}/analysis
POST /analysis/ip
POST /analysis/ip/stream
GET  /analysis/tasks/{task_id}
GET  /analysis/tasks/{task_id}/result
POST /agent/chat
```

完整字段、请求示例、错误码见 `docs/API接口契约.md`，也可以在后端启动后访问 `/docs`。

## 本地 Mock 联调

后端启动：

```powershell
python -m uvicorn agent_service.api.mock_main:app --host 127.0.0.1 --port 8003
```

Swagger：`http://127.0.0.1:8003/docs`

Mock 环境不连接真实数据库、不调用大模型，可以直接用于前端开发。前端如果运行在其他
端口，请配置开发服务器代理到 `http://127.0.0.1:8003`。

## 当前范围说明

- 当前单 IP 分析支持同步返回和 NDJSON 流式进度；
- 任务查询接口已经统一为批量任务可复用结构；
- 批量分析、网段统计和历史对比将在下一阶段实现；
- Agent 不会主动扫描，只读取数据库中的已有扫描数据。
