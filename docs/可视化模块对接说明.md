# 可视化模块对接说明（可直接转发）

智能体后端已经提供单 IP 扫描数据、分析结果、任务状态、任务结果和自然语言问答接口。
第一版请优先完成单 IP 分析结果页面。

## 推荐页面流程

1. 用户输入 IPv4；
2. 调用 `GET /assets/{ip}/analysis` 查询是否已有报告；
3. 有报告则直接展示；
4. 没有报告时，由用户点击“开始分析”，调用 `POST /analysis/ip/stream`；
5. 根据流式节点事件展示分析进度；
6. 收到 `result` 后展示最终报告。

## 页面建议展示

- 摘要：IP、扫描批次、资产类型、风险等级、置信度；
- 服务：端口、协议、服务类型、产品、版本、Banner；
- 风险：等级、标题、说明、置信度；
- 证据：风险对应的扫描或指纹依据；
- 建议：处置建议和优先级；
- 限制：常用端口扫描、版本缺失等数据限制；
- 进度：LangGraph 当前执行节点。

## 主要接口

```text
GET  /assets/{ip}/scan-data
GET  /assets/{ip}/analysis
GET  /assets/{ip}/changes
POST /analysis/ip
POST /analysis/ip/stream
POST /analysis/batch
GET  /analysis/tasks/{task_id}
GET  /analysis/tasks/{task_id}/result
POST /analysis/tasks/{task_id}/report
GET  /analysis/tasks/{task_id}/report
POST /agent/chat
```

完整字段、请求示例、错误码见 `docs/API接口契约.md`，也可以在后端启动后访问 `/docs`。

端口，请配置开发服务器代理到 `http://127.0.0.1:8003`。

## 批量分析页面流程

1. 用户粘贴或选择 2～50 个明确 IPv4；
2. 调用 `POST /analysis/batch`，保存响应中的 `task_id`；
3. 定时调用 `GET /analysis/tasks/{task_id}` 展示总数、成功数和失败数；
4. 父任务变为 `success` 或 `failed` 后，调用 `GET /analysis/tasks/{task_id}/result`；
5. 每个失败子项展示自己的 `error_message`，不要因此隐藏其他成功结果。
6. 调用 `POST /analysis/tasks/{task_id}/report` 生成统计报告；
7. 使用报告中的分布数组绘制资产类型、风险、产品和端口图表。

批量接口不接受 `/9` 等 CIDR 网段。任意 IP 没有扫描数据时整批不会创建，前端应展示
响应中的 `missing_ips`，让用户修正后重新提交。

## 当前范围说明

- 当前单 IP 分析支持同步返回和 NDJSON 流式进度；
- 支持显式 IP 列表的有限批量分析、任务轮询和逐项结果；
- 支持保存并复用批量统计 JSON 报告，统计过程不再次调用模型；
- 支持单 IP 两个扫描批次的服务、产品版本和风险变化对比；
- 第一版后台任务在 FastAPI 进程内执行，服务重启可能中断运行中的批量任务；
- 网段统计和历史对比将在后续阶段实现；
- Agent 不会主动扫描，只读取数据库中的已有扫描数据。
